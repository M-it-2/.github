## About

**M-it-2** is a small independent software organization focused on building
practical systems and developer-oriented tools.

Our projects cover several areas:

- 🎓 **Education & assessment**
- 🧩 **Backend systems & APIs**
- 🖥️ **Desktop applications**
- 🌐 **Web applications**
- 🛠️ **Developer & system tools**
- 🔐 **Infrastructure & automation**

We care about software that is useful, maintainable and actually solves a problem.

## Projects

### 🎓 [AssessX](https://github.com/M-it-2/AssessX)

**Student assessment system for tests, programming assignments and automatic verification.**

A desktop assessment platform with separate Teacher and Student workflows.
Teachers can create tests and coding assignments, assign them to groups,
set deadlines and review results.

Students can complete timed tests, write code in an integrated editor and
have their solutions automatically verified using unit tests.

**Stack:**  
`Java` · `JavaFX` · `Spring Boot` · `Spring Security` · `PostgreSQL` · `JWT` · `OAuth2` · `Docker` · `Maven`

---

### ⚙️ [AssessX Backend](https://github.com/M-it-2/AssessX-backend)

**Backend infrastructure powering AssessX.**

A Spring Boot backend responsible for authentication, authorization,
assignments, tests, programming practices, results and database interaction.

**Stack:**  
`Java` · `Spring Boot` · `Spring Security` · `Hibernate` · `PostgreSQL` · `JWT` · `OAuth2` · `Docker`

---

### 🏃 [PFLAC](https://github.com/M-it-2/PFLAC)

**Physical Fitness Level Assessment Calculator.**

A system for calculating and evaluating physical fitness results based on
defined performance standards, with an API for working with assessment data.

**Stack:**  
`C#` · `FastAPI` · `MySQL` · `Shell`
